# Preprocessed Data Directory

This directory contains **normalized** versions of the tweet datasets with entity replacement for vocabulary reduction.

## Files

### `train_normalized.csv`
Normalized training dataset with entity replacements applied.

### `test_normalized.csv`
Normalized test dataset using the same normalization rules as training.

### `normalizer_config.json`
Configuration file containing:
- List of tickers replaced
- List of company names replaced
- Normalization settings (mentions, URLs, prices, percentages)

## Normalization Rules

The following deterministic transformations are applied:

| Entity Type | Pattern | Replacement | Example |
|-------------|---------|-------------|---------|
| **Ticker Symbols** | `$TSLA`, `AAPL` | `[TICKER]` | `$TSLA up 5%` → `[TICKER] up 5%` |
| **Company Names** | `Tesla`, `Apple` | `[COMPANY]` | `Tesla announces` → `[COMPANY] announces` |
| **User Mentions** | `@username` | `[USER]` | `@elonmusk says` → `[USER] says` |
| **URLs** | `https://...` | `[URL]` | `See https://...` → `See [URL]` |
| **Prices** (optional) | `$100`, `$1.5M` | `[PRICE]` | Currently disabled |
| **Percentages** (optional) | `5%`, `10.5%` | `[PERCENT]` | Currently disabled |

## Why Offline Preprocessing?

**Advantages:**
- ✅ **Vocabulary Reduction**: Reduces unique tokens by 50-100, making the model more efficient
- ✅ **Better Generalization**: Model learns sentiment patterns independent of specific companies
- ✅ **Consistent Normalization**: Val/test sets normalized identically (no randomness)
- ✅ **Faster Training**: No per-batch preprocessing overhead
- ✅ **Handles Unseen Entities**: New tickers in test set don't cause OOV issues

**Expected Impact:** +3-6% accuracy improvement

## Usage

### In Training Pipeline

```python
# Load pre-normalized data instead of raw data
train_df = pd.read_csv('preprocessed_data/train_normalized.csv')
test_df = pd.read_csv('preprocessed_data/test_normalized.csv')

# Use 'text_normalized' column instead of 'text'
train_texts = train_df['text_normalized'].values
```

### Regenerate with Different Settings

```python
from preprocessing.text_normalizer import TextNormalizer

# Load existing config
normalizer = TextNormalizer.from_config('preprocessed_data/normalizer_config.json')

# Or create new normalizer with custom settings
normalizer = TextNormalizer(
    vocab_analysis_path='outputs/vocab_analysis/vocabulary_analysis.json',
    normalize_prices=True,  # Enable price normalization
    normalize_percentages=True  # Enable percentage normalization
)

# Normalize data
df_normalized = normalizer.normalize_dataframe(df, text_column='text')
```

## Reproducibility

All normalization is **deterministic** and can be reproduced using the saved `normalizer_config.json`.

To apply the same normalization to new data:

```python
from preprocessing.text_normalizer import TextNormalizer

# Load exact same configuration
normalizer = TextNormalizer.from_config('preprocessed_data/normalizer_config.json')

# Apply to new data
new_df['text_normalized'] = new_df['text'].apply(normalizer.normalize)
```
